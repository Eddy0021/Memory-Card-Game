# React + TypeScript Project

This project is a React Vite application set up with TypeScript.
Project name: Memory Game
Design by: Bene Studio

## Installation

To get started with this project, follow these steps:

### 1. Clone the repository

```bash
git clone https://github.com/Eddy0021/memory-game-benestudio
cd memory-game-benestudio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```
